Prototype assumptions and integration

Queue runs from 1 to 24; a smaller number is earlier. A value of −1 displays as – and never participates in a move or its average. These rows keep their values and table positions.

The wheel starts at the selected queued rows’ average, or at the start of the queue when none are queued. Moving rows are lifted out of the wheel, so its numbers identify the remaining rows’ current Queue values. A drop preserves the packet’s order and renumbers the queue consecutively.

The enable switch simulates API configuration. One insertion request supplies the packet and the remaining row to insert before (or the end). The demo host applies it. This standalone HTML explores the gesture; it does not change the native TableView API.
